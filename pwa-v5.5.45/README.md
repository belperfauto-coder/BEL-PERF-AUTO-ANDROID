# BEL-PERF'AUTO V5.5.45

Base complète : V5.5.44.

## Synchronisation
- restauration automatique de la session Supabase au démarrage ;
- session persistante et renouvellement automatique ;
- ancienne configuration vide ignorée au profit de la configuration par défaut valide ;
- e-mail de synchronisation mémorisé ;
- bouton Se connecter réinitialise proprement la session puis synchronise.

## Forfait / marge interne
Aucune seconde bascule n'est nécessaire dans la gestion interne.
Le mode choisi sur la ligne de facture (Horaire HT ou Forfait HT) est repris automatiquement.
Pour un forfait, le détail interne affiche : prestation, mode, temps réel, coût interne, vente HT, marge € et marge %.
