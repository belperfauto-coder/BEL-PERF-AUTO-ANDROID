BEL-PERF'AUTO — APPLICATION ANDROID V2

FONCTIONS :
- Tableau de bord
- Ordres de réparation
- Fiches clients / véhicules et historique
- Immatriculation, VIN, année, kilométrage
- Photos du véhicule / des travaux (jusqu'à 6 par OR)
- Signature manuscrite du client
- Statuts Attente / En cours / Terminé
- Boutons Appeler et SMS
- Génération d'un ordre de réparation imprimable / enregistrable en PDF
- Création de devis et factures
- Lignes main-d'œuvre / pièces, quantité et prix
- Remise
- TVA configurable à 0 % ou 20 %
- Taux horaire configurable
- Sauvegarde locale et export/import JSON

COMPILATION APK :
1. Installer Android Studio sur un ordinateur.
2. Décompresser ce dossier.
3. Dans Android Studio : Open > sélectionner BEL-PERF-AUTO_Android_V2.
4. Attendre la synchronisation Gradle.
5. Build > Build App Bundle(s) / APK(s) > Build APK(s).
6. APK : app/build/outputs/apk/debug/app-debug.apk

IMPORTANT :
- Le logo original BEL-PERF'AUTO n'est pas intégré dans cette archive car aucun fichier logo source n'a été fourni dans ce tour.
- Le projet est prévu pour fonctionner hors ligne.
- Les photos/signatures augmentent la taille du stockage local. Exporter régulièrement une sauvegarde.
