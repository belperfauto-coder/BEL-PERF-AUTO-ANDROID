# BEL-PERF'AUTO PWA — branche de développement

Base de référence : V5.5.26 (Netlify).

Cette branche est réservée à la PWA de facturation / gestion atelier et reste séparée du projet Android présent sur main.

## Objectifs
- stabiliser l'affichage mobile Samsung sans casser la version PC ;
- restaurer et fiabiliser l'impression A4, notamment l'en-tête complet avec la voiture et les interventions possibles ;
- conserver l'import de documents par IA GPT-5.4 ;
- améliorer le flux Devis → OR → travaux → contrôle → facture → encaissement ;
- création / rapprochement automatique des articles de stock ;
- calcul de rentabilité interne ;
- photos véhicule et checklist atelier ;
- rappels clients ;
- tableau de bord atelier ;
- état de synchronisation Supabase ;
- mode atelier téléphone ;
- mise à jour PWA fiable.

## Règle de sécurité
Ne pas fusionner cette branche dans main tant que la PWA n'a pas été validée sur PC, impression A4 et téléphone.
